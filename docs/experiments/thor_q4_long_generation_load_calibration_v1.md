# Thor Q4 long-generation load calibration v1

## Purpose

The original long-generation serving trace overloaded even MaxClock. All policies
therefore failed the end-to-end SLO, so its energy deltas are not constrained wins.
This protocol first locates a MaxClock-feasible arrival rate, freezes that rate and
only then permits a multi-policy comparison.

`arrival_scale` multiplies the scheduled timestamp of every request generated by
the original `RequestGenerator`. Workload choices and seeds remain unchanged.
Larger scales mean lighter offered load. All policies in a later comparison must
use the exact same saved traces.

## Stage 1: coarse boundary scan

The coarse scan runs MaxClock for one 300-second repeat at scales 2, 4, 8, 12 and
16. It is only a bracket search, not a final result.

```bash
cd /home/wt/energyinfra/Energyinfra-main
sudo -E bash scripts/active/run_thor_long_generation_calibration_nohup.sh coarse
```

The report is written to:

```text
data/protocol_v2/thor_q4_long_generation_load_calibration_v1/coarse/RESULTS.md
```

## Stage 2: refine the boundary

The coarse scan brackets the observed boundary between scales 4 and 8. Refine it
with one 600-second repeat at scales 5, 6 and 7:

```bash
sudo -E bash scripts/active/run_thor_long_generation_calibration_nohup.sh refine
```

## Stage 3: confirm one boundary point

Use the smallest refined scale whose MaxClock result passes the observed 95 percent
attainment requirement. The confirm phase uses three independent 600-second traces.

```bash
sudo -E bash scripts/active/run_thor_long_generation_calibration_nohup.sh confirm --scale SCALE
```

Do not claim a feasible operating region from the coarse scan alone. A confirmed
scale becomes the frozen load for the later Dynamic, MaxClock and Pareto-policy
comparison. Request-level confidence intervals remain descriptive rather than a
population guarantee.

## Recovery

The runner restores the original hardware state on normal completion, exceptions
and graceful termination. If an ungraceful stop leaves a pending marker, run:

```bash
sudo -E bash scripts/active/run_thor_long_generation_calibration_nohup.sh restore
```
