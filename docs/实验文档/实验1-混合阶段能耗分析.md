# 实验 1：混合阶段能耗分析

> **⚠️ 数据失效说明 (2026-05-15)**
>
> 本实验使用的 `userspace` GPU governor 存在严重 bug：在推理负载下无法锁定 GPU 频率，
> GPU 会自发跳频至 1300MHz（最大值）。这导致所有 "GPU 频率无显著影响" 的结论是错误的。
>
> 修正后的实验（实验 3）使用 `performance` governor，672 runs，14 workloads，证实：
> - GPU 频率从 306→918 MHz，吞吐量提升约 2.5×（而非本报告中的持平）
> - GPU 918MHz 在 10/14 个负载中是最优配置（而非本报告中的 612MHz）
> - GPU SoC 功耗随频率显著变化（8→19W，而非本报告中的持平 ~4W）
>
> **修正后的数据**见 [实验3-扩展负载汇率表](实验3-扩展负载汇率表.md)
>
> 本文档保留作为历史记录，但其中的 GPU 相关结论已失效。功耗域分析和 CPU 频率效应部分仍有参考价值。

## 实验结果

### 1.1 各配置性能与能耗总览

| 配置 | GPU (MHz) | CPU (MHz) | 吞吐 (tok/s) | 功耗 (W) | E/token (J) | tok/J |

| GPU612_CPU1036 | 612 | 1036 | 38.6 | 42.2 | **1.187** | **0.84** |
| GPU918_CPU1036 | 918 | 1036 | 36.7 | 42.2 | 1.339 | 0.80 |
| GPU1300_CPU1036 | 1300 | 1036 | 38.7 | 42.4 | 1.194 | 0.84 |
| GPU306_CPU1497 | 306 | 1497 | 38.6 | 42.3 | 1.215 | 0.83 |
| GPU612_CPU1497 | 612 | 1497 | 39.1 | 42.9 | 1.200 | 0.83 |
| GPU918_CPU1497 | 918 | 1497 | 39.1 | 42.0 | 1.215 | 0.83 |
| GPU1300_CPU1497 | 1300 | 1497 | 39.1 | 43.1 | 1.206 | 0.83 |
| GPU306_CPU2201 | 306 | 2201 | 39.4 | 43.7 | 1.220 | 0.82 |
| GPU612_CPU2201 | 612 | 2201 | 39.5 | 43.7 | 1.226 | 0.82 |

> ⚠️ 上表中 GPU 306/612/918/1300 在 CPU ≥ 1497MHz 时吞吐量几乎持平（~39 tok/s），
> 这正是 governor bug 的表现：GPU 实际都在 1300MHz 运行。

### 1.2 GPU 频率效应

> ⚠️ 以下结论已失效。GPU 在 `userspace` governor 下实际频率跳至 1300MHz，
> 导致看似 "GPU 频率无影响"。修正后数据见实验 3。

| GPU 频率 | 平均功耗 (W) | E/token (J) | 吞吐 (tok/s) |
|:---:|:---:|:---:|:---:|
| 306 MHz | 16.2* / 42.7** | 1.423* / 1.215** | 11.7* / 38.9** |
| 612 MHz | 42.2 | **1.187** | 38.6 |
| 918 MHz | 42.0 | 1.339 | 36.7 |
| 1300 MHz | 43.2 | 1.194 | 39.1 |

\* GPU306_CPU1036 (CPU 最低频时 GPU 306MHz 成为瓶颈)
\** 排除 CPU1036 后的平均值

**原始发现（已失效）**：
- GPU 306MHz 在 CPU ≥ 1497MHz 时吞吐量与高频 GPU 持平（~39 tok/s） → 实际是 governor bug
- GPU 612MHz 是全局能效最优点（1.187 J/token） → 实际是 CPU 1036MHz 的低功耗优势
- GPU 918MHz 吞吐略低于 612MHz → 噪声，实际频率都在 1300MHz

### 1.3 CPU 频率效应

> ✅ CPU 频率相关结论仍然有效（CPU governor `userspace` 工作正常）

| CPU 频率 | 平均功耗 (W) | E/token (J) | 吞吐 (tok/s) |
|:---:|:---:|:---:|:---:|
| 1036 MHz | 35.7 | 1.286 | 31.2 |
| 1497 MHz | 42.8 | **1.206** | 39.0 |
| 2201 MHz | 43.7 | 1.235 | 39.3 |

**关键发现**（仍有效）：
- CPU 1497MHz 是能效最优点（1.206 J/token）
- CPU 2201MHz 功耗增加 1W 但吞吐几乎不变（39.3 vs 39.0 tok/s）

### 1.4 功耗域分解

> ⚠️ GPU SoC 功耗数据受 governor bug 影响，实际 GPU 都在 1300MHz 运行

## 分析结论

> ⚠️ 以下第 1、3、4 条结论已失效（基于错误的 GPU 频率数据）

1. ~~GPU 612MHz 是混合推理的能效最优点~~ → 修正：GPU 918MHz 在长输出中更优
2. **CPU 1497MHz 是 CPU 能效甜点**（仍有效）
3. ~~GPU 306MHz 在 CPU ≥ 1497MHz 时吞吐量不降~~ → governor bug 所致
4. ~~功耗主体在 CPU 和系统域，GPU 仅 ~4W~~ → 实际 GPU SoC 功耗随频率显著变化（8-30W）
